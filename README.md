📋 Diário de Bordo Digital

Aplicação web criada para melhorar a comunicação no setor, registrando de forma clara e organizada as ocorrências diárias e avisos entre os turnos.

💡 Sobre o Projeto

Este projeto nasceu a partir da vivência prática na rotina operacional de segurança patrimonial. Observando o dia a dia das equipes, notei que o registro manual em livros físicos muitas vezes dificultava a legibilidade das anotações, a busca por históricos e a passagem de plantão.

O Diário de Bordo Digital foi desenvolvido como uma solução web prática e intuitiva para substituir ou complementar os livros físicos, garantindo que nenhuma informação importante se perca entre os turnos.

✨ Funcionalidades Principais

Registro de Ocorrências: Criação rápida de relatos detalhados com data, hora e responsável.

Mural de Avisos: Destaque para recados importantes na troca de turno.

Leitura Clara e Padronizada: Fim dos problemas com caligrafia ilegível ou rasuras.

Consulta Rápida: Facilidade para localizar registros anteriores sem precisar folhear páginas físicas.
